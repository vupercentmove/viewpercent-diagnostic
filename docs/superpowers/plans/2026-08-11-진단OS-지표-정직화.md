# 진단 OS 지표 정직화 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 대시보드에서 구조적으로 영원히 0%인 「카톡 CTA 전환율」을 제거하고, 죽은 집계 코드를 지우고, 모든 숫자에 분모·출처를 붙이고, 유입경로별 완료 건수를 볼 수 있게 한다.

**Architecture:** 집계 로직은 순수 함수로 `lib/inflow-source.ts`에 두고 vitest로 TDD한다. 대시보드(`app/admin/dashboard/page.tsx`)는 그 함수를 호출해 렌더링만 한다. DB 스키마 변경 없음 — `utm` 컬럼과 조회 경로는 이미 있다.

**Tech Stack:** Next.js (App Router) · TypeScript · Tailwind · vitest · Supabase(PostgREST + RPC) · Vercel

## Global Constraints

- 스펙 정본: `docs/superpowers/specs/2026-08-11-진단OS-지표-정직화-design.md`
- **DB 스키마·RPC를 수정하지 않는다.** `get_diagnostic_stats()`는 레포 밖 자산이며 화면에서 안 쓰면 되는 문제다.
- **RLS는 건드리지 않는다.** 10개 테이블 RLS 미적용은 알려진 별건이며 이 계획의 범위 밖이다.
- 집계 키 우선순위는 **`utm.ref` → `utm.utm_source` → `"미상"`** 로 고정한다. 이 순서를 바꾸지 않는다.
- **utm 없는 건을 숨기지 않는다.** `"미상"`으로 그대로 노출한다.
- 배선 실증 레코드(`ref=wiring-test`)는 **DB에서 지우지 않고** 집계에서만 제외한다.
- 이 저장소에는 **React 컴포넌트 테스트 도구가 없다**(devDependencies에 vitest만 있고 testing-library 없음). 따라서 UI 변경은 단위 테스트 대상이 아니며 `npm run build`(타입체크) + 실화면 확인으로 검증한다. **없는 테스트를 있는 것처럼 쓰지 않는다.**
- 커밋 메시지 접두사는 저장소 관례를 따른다: `feat:` / `fix:` / `docs:` / `refactor:`
- 작업 브랜치: `feat/full-deep-mode` (현재 브랜치. 새로 만들지 않는다)

### Task 5: 유입경로 집계 함수 (TDD)

**Files:**
- Create: `lib/inflow-source.ts`
- Test: `lib/inflow-source.test.ts`

**Interfaces:**
- Consumes: `DiagnosticRow.utm`의 형태 `Record<string, string> | null` (`lib/supabase-admin.ts`에 이미 정의됨)
- Produces:
  - `WIRING_TEST_REF: "wiring-test"`
  - `InflowCount { source: string; count: number }`
  - `resolveInflowSource(utm: Record<string, string> | null | undefined): string`
  - `aggregateInflowSources(rows: { utm?: Record<string, string> | null }[]): InflowCount[]`

  Task 6이 `aggregateInflowSources`와 `InflowCount`를 그대로 import한다.

- [ ] **Step 1: 실패하는 테스트를 쓴다**

`lib/inflow-source.test.ts`를 만든다.

```ts
import { describe, it, expect } from "vitest";
import {
  resolveInflowSource,
  aggregateInflowSources,
  WIRING_TEST_REF,
} from "./inflow-source";

describe("resolveInflowSource", () => {
  it("ref가 있으면 ref를 쓴다", () => {
    expect(resolveInflowSource({ ref: "ig", utm_source: "instagram" })).toBe("ig");
  });

  it("ref가 없으면 utm_source로 내려간다", () => {
    expect(resolveInflowSource({ utm_source: "instagram" })).toBe("instagram");
  });

  it("공백뿐인 ref는 값이 없는 것으로 본다", () => {
    expect(resolveInflowSource({ ref: "   ", utm_source: "kakao" })).toBe("kakao");
  });

  it("둘 다 없으면 미상", () => {
    expect(resolveInflowSource({})).toBe("미상");
  });

  it("utm이 null이면 미상", () => {
    expect(resolveInflowSource(null)).toBe("미상");
  });
});

describe("aggregateInflowSources", () => {
  it("경로별 건수를 센다", () => {
    const rows = [
      { utm: { ref: "ig" } },
      { utm: { ref: "ig" } },
      { utm: { ref: "kakao" } },
    ];
    expect(aggregateInflowSources(rows)).toEqual([
      { source: "ig", count: 2 },
      { source: "kakao", count: 1 },
    ]);
  });

  it("utm 없는 건을 미상으로 남긴다 — 숨기지 않는다", () => {
    const rows = [{ utm: null }, { utm: null }, { utm: { ref: "ig" } }];
    expect(aggregateInflowSources(rows)).toEqual([
      { source: "미상", count: 2 },
      { source: "ig", count: 1 },
    ]);
  });

  it("배선 실증 레코드는 집계에서 뺀다", () => {
    const rows = [{ utm: { ref: WIRING_TEST_REF } }, { utm: { ref: "ig" } }];
    expect(aggregateInflowSources(rows)).toEqual([{ source: "ig", count: 1 }]);
  });

  it("건수가 같으면 이름 오름차순으로 정렬한다", () => {
    const rows = [{ utm: { ref: "kakao" } }, { utm: { ref: "ig" } }];
    expect(aggregateInflowSources(rows)).toEqual([
      { source: "ig", count: 1 },
      { source: "kakao", count: 1 },
    ]);
  });

  it("빈 목록은 빈 배열", () => {
    expect(aggregateInflowSources([])).toEqual([]);
  });
});
```

```ts
 * 유입경로 집계 — diagnostic_results.utm에서 채널을 뽑아 완료 건수를 센다.
 *
 * 집계 키 우선순위는 ref → utm_source → "미상" 으로 고정한다.
 * 스펙: docs/superpowers/specs/2026-08-11-진단OS-지표-정직화-design.md
 */

/** 배선 실증용 레코드의 ref 값. DB에서 지우지 않고 집계에서만 제외한다. */
export const WIRING_TEST_REF = "wiring-test";

export interface InflowCount {
  source: string;
  count: number;
}

/** utm 객체 하나에서 집계 키를 뽑는다. */
export function resolveInflowSource(
  utm: Record<string, string> | null | undefined
): string {
  const ref = utm?.ref?.trim();
  if (ref) return ref;
  const source = utm?.utm_source?.trim();
  if (source) return source;
  return "미상";
}

/**
 * 완료 레코드를 유입경로별 건수로 집계한다.
 * 건수 내림차순, 같으면 이름 오름차순.
 */
export function aggregateInflowSources(
  rows: { utm?: Record<string, string> | null }[]
): InflowCount[] {
  const counts = new Map<string, number>();
  for (const row of rows) {
    const source = resolveInflowSource(row.utm);
    if (source === WIRING_TEST_REF) continue;
    counts.set(source, (counts.get(source) ?? 0) + 1);
  }
  return [...counts.entries()]
    .map(([source, count]) => ({ source, count }))
    .sort((a, b) => b.count - a.count || a.source.localeCompare(b.source));
}
```
