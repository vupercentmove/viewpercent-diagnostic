**Goal:** 진단 문항 37개마다 "이 사실을 어디서 확인하는가"를 한 줄로 보여주고, 결과 화면 약점 단계에 해석 예시를 붙인다.

**Architecture:** 표시용 데이터를 스코어링 데이터에서 분리한다. `lib/question-examples.ts`(문항 id → 문자열)와 `lib/stage-examples.ts`(stageId → 문자열)를 새로 만들고, 세 문항 화면이 공유하는 표시 컴포넌트 하나를 둔다. 기존 `lib/full-deep-content.ts`의 `QUESTION_INSIGHT`와 `lib/likert-scale.ts`가 같은 패턴이다.

**Tech Stack:** Next.js 14 (App Router) · TypeScript strict · Tailwind CSS 3 · Vitest

설계 문서: `docs/superpowers/specs/2026-08-18-문항별-예시-design.md`

## Global Constraints

- **스코어링 불변식 금지**: `lib/questions.ts`·`lib/deep-questions.ts`의 `id`·`answerType`·`stageId`·`REVERSE_YN`을 수정하지 않는다. 문항 문구도 건드리지 않는다.
- **카피 정본**: `docs/진단-언어-원칙-2026-07-25.md`를 따른다.
  - 금지어: `충분히` `전략적으로` `적극적으로` `의도적으로` `무조건` `꼭` `무료`
  - 느낌표 금지. 명령형(`~하세요`) 지양. 성과 약속(`~하면 더 팔립니다`) 금지.
  - 비유 체계: `돌아서다`=고객 행동(원인) / `새다`=돈의 결과. 섞지 않는다.
  - 호칭은 `대표님`. `당신` 금지.
- **예시의 역할**: 어디서 확인하는지만 알려준다. 정답을 알려주거나 판단을 유도하지 않는다.
- **솔루션 중립**: 카페24·아임웹·GA 등은 예로만 들고 그것만이 답인 것처럼 쓰지 않는다.
- **한 문항 = 한 문장.** 27문항 피로를 억제하기 위해 길이를 짧게 유지한다.
- **승인 게이트**: 예시 43개 초안은 Task 5에서 사용자 승인을 받은 뒤에만 최종 커밋한다.

```ts
// lib/question-examples.test.ts
import { describe, it, expect } from "vitest";
import { QUICK_QUESTIONS } from "./questions";
import { DEEP_QUESTIONS } from "./deep-questions";
import { QUESTION_EXAMPLE, getQuestionExample } from "./question-examples";

const ALL_IDS = [
  ...QUICK_QUESTIONS.map((q) => q.id),
  ...DEEP_QUESTIONS.map((q) => q.id),
];

describe("question-examples", () => {
  it("모든 문항에 예시가 있다 — 키 집합이 문항 id 집합과 정확히 같다", () => {
    expect(Object.keys(QUESTION_EXAMPLE).sort()).toEqual([...ALL_IDS].sort());
  });

  it("빈 문자열인 예시가 없다", () => {
    for (const [id, text] of Object.entries(QUESTION_EXAMPLE)) {
      expect(text.trim(), `${id}가 비어 있다`).not.toBe("");
    }
  });

  it("getQuestionExample: 없는 id는 빈 문자열", () => {
    expect(getQuestionExample("존재하지않는id")).toBe("");
  });

  it("getQuestionExample: 있는 id는 해당 예시", () => {
    expect(getQuestionExample("d4a")).toBe(QUESTION_EXAMPLE["d4a"]);
  });
});
```

```tsx
import { getQuestionExample } from "@/lib/question-examples";

/**
 * 문항 아래에 "어디서 확인하는가"를 한 줄로 보여준다.
 *

  const example = getQuestionExample(questionId);
  if (!example) return null;

  return (
    <p className="text-[12px] text-gray-400 leading-relaxed mb-3">{example}</p>
  );
}
```
