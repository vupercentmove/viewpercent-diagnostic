# ref 슬러그 대응표

진단 OS 유입경로 추적용 `?ref=` 값과 실제 게시물의 대응표.
**슬러그만 있고 이 표가 없으면 몇 달 뒤 그 숫자가 뭘 세는지 모르게 된다.**

## 규칙

- 영문 소문자·숫자·하이픈만, 20자 이내
- 게시물 주제를 알아볼 수 있게
- **한 번 쓴 슬러그는 재사용하지 않는다** — 재사용하면 서로 다른 게시물의 완료가 한 칸에 합쳐진다
- 날짜(`YYMMDD`)는 쓰지 않는다 — 하루에 여러 건 올리면 안 갈린다

## 고정 값

| ref | 경로 |
|---|---|
| `ig` | 인스타그램 @coach_unick 프로필 링크 |
| `kakao` | 카카오톡 채널 |
| `wiring-test` | 배선 실증용. 집계에서 제외된다 |
