# ref 슬러그 대응표

진단 OS 유입경로 추적용 `?ref=` 값과 실제 게시물의 대응표.
**슬러그만 있고 이 표가 없으면 몇 달 뒤 그 숫자가 뭘 세는지 모르게 된다.**

## 규칙

- 인스타그램 게시물별 ref는 `ig-<슬러그>` 접두사를 붙인다 (예: `ig-roas-3step`)
- 영문 소문자·숫자·하이픈만, 20자 이내
- 게시물 주제를 알아볼 수 있게
- **한 번 쓴 슬러그는 재사용하지 않는다** — 재사용하면 서로 다른 게시물의 완료가 한 칸에 합쳐진다
- 날짜(`YYMMDD`)는 쓰지 않는다 — 하루에 여러 건 올리면 안 갈린다

## 한계

집계는 정확 문자열 일치라, `ig-*` 슬러그가 쌓일수록 「유입경로별 완료」 카드는 게시물 하나당 한 줄씩 늘어난다 — 인스타그램 채널 전체를 합산하는 행은 따로 없다. 게시물별 행이 너무 많아져 읽기 어려워지면, `ig-` 접두사 기준으로 묶어 보여주는 롤업은 후속 작업으로 남겨둔다.

## 고정 값

| ref | 경로 |
|---|---|
| `ig` | 인스타그램 @coach_unick 프로필 링크 |
| `kakao` | 카카오톡 채널 |
| `wiring-test` | 배선 실증용. 집계에서 제외된다 |
